# Dahua Downloader

Android-приложение для поиска и выгрузки записей с совместимых регистраторов Dahua.

Устройство, использовавшееся при первоначальной настройке проекта: `DHI-NVR2104-P-4KS2`. Совместимость с другими моделями и версиями прошивки необходимо проверять отдельно.

## Реализовано

- Подключение к регистратору по IP-адресу или доменному имени через Dahua NetSDK.
- Поиск архива по каналу и временному диапазону.
- Загрузка выбранного временного интервала одним файлом через `DownloadByTimeEx`.
- Загрузка отдельных файлов архива частями с продолжением по смещению после сетевого обрыва.
- Очередь загрузок, ограничение параллельности и журнал.
- Сохранение результатов в `Загрузки/Dahua`.
- Опциональная конвертация DAV в MP4, если FFmpeg доступен в сборке.
- Сохранение очереди и частичных файлов между перезапусками приложения.

## Удалённое P2P-подключение (экспериментально)

Добавлен отдельный режим подключения по серийному номеру через открытую Go-библиотеку `github.com/blackjid/dahua-p2p` (MIT, зафиксированная версия указана в `p2pbridge/go.mod`). Go-компонент собирается в Android AAR через `gomobile` в GitHub Actions.

Режим поднимает P2P-туннель и локальный TCP-мост на `127.0.0.1:37778`, после чего NetSDK пробует подключиться через него к TCP-порту регистратора `37777`. Обычный режим по IP остаётся доступен.

**Важно:** upstream-библиотека документирует и проверяет прежде всего RTSP-туннель. Использование её TCP-транспорта для NetSDK на порту `37777` добавлено как эксперимент и не считается подтверждённым до проверки на реальном регистраторе. Совместимость зависит от модели, прошивки, состояния P2P и облачной инфраструктуры Dahua. Если вход не проходит, отключите экспериментальный режим и используйте IP через VPN.

Библиотека использует серийный номер и учётные данные самого регистратора; обход авторизации и закрытые ключи DMSS/SmartPSS не используются. Пароль не сохраняется в настройках приложения.

Условия лицензии и уведомление о сторонней библиотеке: [p2pbridge/THIRD_PARTY_NOTICES.md](p2pbridge/THIRD_PARTY_NOTICES.md).

## Сборка

Требуются JDK 17, Android SDK Platform 35 и Gradle 8.9. Откройте проект в Android Studio либо выполните из корня репозитория:

```bash
gradle --no-daemon assembleDebug
```

Нативные библиотеки проекта рассчитаны на ABI `arm64-v8a`.

## Безопасность

- Не помещайте пароли регистратора, ключи P2P или закрытые SDK-файлы в Git.
- Пароль регистратора вводится при подключении и не сохраняется в настройках приложения.
- Для удалённого доступа предпочтительнее использовать защищённый VPN до локальной сети, если прямой P2P SDK ещё не настроен.
