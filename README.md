# Dahua Downloader

Android-приложение для поиска и выгрузки записей с совместимых регистраторов Dahua.

Устройство, использовавшееся при первоначальной настройке проекта: `DHI-NVR2104-P-4KS2`. Совместимость с другими моделями и версиями прошивки необходимо проверять отдельно.

## Реализовано

- Подключение к регистратору по IP-адресу или доменному имени через Dahua NetSDK.
- Поиск архива по каналу и временному диапазону.
- Загрузка файлов архива частями с продолжением по смещению после сетевого обрыва.
- Очередь загрузок, ограничение параллельности и журнал.
- Сохранение результатов в `Загрузки/Dahua`.
- Опциональная конвертация DAV в MP4, если FFmpeg доступен в сборке.
- Сохранение очереди и частичных файлов между перезапусками приложения.

## Ограничение удалённого P2P

Подключение через P2P по серийному номеру пока не реализовано. В проекте присутствует нативная библиотека `libToUProxy.so`, но отсутствует соответствующая Java-библиотека `libToUProxy.jar`. Также отсутствуют выданные Dahua параметры P2P-клиента для конкретного SDK-пакета.

Обычный NetSDK-вход по IP и P2P-туннель — разные этапы. Для удалённого P2P требуется официальный совместимый proxy SDK, документированный набор параметров сервиса и проверка его совместимости с моделью/прошивкой регистратора. Приложение не должно использовать закрытые ключи DMSS/SmartPSS, извлечённые из сторонних приложений, или выдуманные параметры.

Перед подключением к P2P убедитесь, что P2P включён на самом регистраторе и его статус отображается как Online. Сетевые требования зависят от региона, протокола и версии устройства; сверяйтесь с документацией Dahua для конкретного оборудования.

Подробный технический аудит и список недостающих компонентов: [docs/P2P_INTEGRATION_STATUS.md](docs/P2P_INTEGRATION_STATUS.md).

## Сборка

Требуются JDK 17, Android SDK Platform 35 и Gradle 8.9. Откройте проект в Android Studio либо выполните из корня репозитория:

```bash
gradle --no-daemon assembleDebug
```

Нативные библиотеки проекта рассчитаны на ABI `arm64-v8a`.

## Безопасность

- Не помещайте пароли регистратора, ключи P2P или закрытые SDK-файлы в Git.
- Пароль регистратора вводится при подключении и не сохраняется в настройках приложения.
- Для удалённого доступа предпочтительнее использовать защищённый VPN до локальной сети, если прямой P2P SDK ещё не настроен.
